Information Theory · Chapter 6.3

How much does one variable
tell us about another?

Mutual information is not about whether two values move in the same direction. It asks a deeper question: after seeing one variable, how much uncertainty about the other disappears?

Build the intuitionJump to cheat sheet

What if I already know something else?

Conditional mutual information

I(X;Y|Z) asks how much new information Y gives about X after Z is already known.

House-price exampleBedrooms may predict price. But after you know square footage, do bedrooms still add much? Conditional MI measures exactly that leftover value.
I(X;Y|Z)= information from Ythat Z did not already reveal

Why not just use correlation?

MI sees beyond straight lines

Pearson correlation looks mainly for linear movement. Mutual information detects any statistical dependence.

Can we compare MI across different problems?

Normalized mutual information

Raw MI has no universal scale. NMI divides shared information by the maximum that could be shared, producing a score from 0 to 1.

Think percentage, not points“8 points” means little without the total. “80%” is comparable.
One important warning

There are several NMI formulas. Always check which denominator a library uses before comparing scores.

How do we estimate MI for real-valued data?

Bins, neighbors, and MIC

Continuous values do not come with a ready-made probability table. We must estimate it.

  • Histogram: easy, but sensitive to bin size and boundaries.
  • KNN / KSG: estimates local density from nearby points.
  • MIC: searches many grids for one that captures a relationship.
2 × 2
4 × 3
8 × 5

Different grids reveal different patterns.

Can processing create information?

Data processing inequality

If X → Y → Z, then Z is made only from Y. Processing may preserve or discard information about X, but it cannot invent more.

Can compression keep everything that matters?

Sufficient statistics

A statistic s(D) is sufficient for a parameter θ when it keeps all the information in dataset D that matters for learning θ.

A sufficient statistic is task-specific lossless compression.

What if the features barely contain the answer?

Fano’s inequality

If features X contain little information about label Y, no classifier—however clever—can achieve a tiny error rate.

Predict tomorrow’s rain from shoe colorA powerful model cannot recover information that the feature never contained.

High MI makes good prediction possible, not guaranteed. You still need enough data and a suitable model.

03 · REMEMBER IT

The one-screen cheat sheet.

Core meaningI(X;Y)=H(X)−H(X|Y)

How much uncertainty about X disappears after seeing Y.

IndependenceI(X;Y)=0 ⇔ X ⟂ Y

No shared information means statistical independence.

SymmetryI(X;Y)=I(Y;X)

Shared information has no direction.

ConditioningI(X;Y|Z)

Y’s extra value after Z is already known.

ProcessingX→Y→Z ⇒ I(X;Z)≤I(X;Y)

Processing cannot create information about the source.

Predictionlow I(X;Y) ⇒ error floor

No model can extract a signal that is not there.
